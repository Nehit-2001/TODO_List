# ✅ To-Do List App (React + Tailwind + LocalStorage)

A simple and stylish **To-Do List Application** built with **React** and **Tailwind CSS**.  
It allows users to **add, mark as completed, and delete tasks** with persistence using **localStorage**.

---

## ✨ Features
- ➕ Add new tasks
- ✅ Mark tasks as completed
- ❌ Delete tasks
- 💾 Tasks are saved in **localStorage** (persist after refresh)
- 🎨 Clean and responsive UI with **Tailwind CSS**

---

## 🛠️ Tech Stack
- **React** (Functional Components + Hooks)
- **Tailwind CSS**
- **localStorage** (for persistence)
